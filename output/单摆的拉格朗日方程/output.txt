==================================================
单连杆拉格朗日方程教学实例
==================================================

【系统参数】
质量 m = 1.0 kg
质心距离 L = 0.5 m
转动惯量 I = 0.1 kg·m²

==================================================
1. 拉格朗日函数
==================================================

● 动能 T = 1/2 * J * θ̇²
  等效转动惯量 J = 0.350 kg·m²

● 势能 P = m*g*L*(1-cosθ)  (以最低点为零点)

● 拉格朗日函数 L = T - P

==================================================
2. 运动方程
==================================================

● 拉格朗日方程：d/dt (∂L/∂θ̇) - ∂L/∂θ = 0

● 得到运动方程：
  J * θ̈ + m*g*L*sinθ = 0
  即：0.350 * θ̈ + 4.900 * sinθ = 0

==================================================
3. 数值求解
==================================================

初始条件: θ=30°, θ̇=0
求解时间: 0-10秒

==================================================
4. 能量分析
==================================================

初始总能量: 0.656 J
最终总能量: 0.651 J
能量变化: -0.005 J (应接近0，机械能守恒)

==================================================
5. 结果可视化
==================================================

==================================================
• 拉格朗日方程：d/dt(∂L/∂θ̇) - ∂L/∂θ = 0
• 运动方程：0.350θ̈ + 4.900sinθ = 0
